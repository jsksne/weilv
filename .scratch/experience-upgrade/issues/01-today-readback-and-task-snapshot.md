# 01 — 今日读回：当天已保存任务可恢复（F4 数据基础）

**What to build:** 用户刷新页面或隔几分钟回到"今日"，看到的不再是全新一批推荐，而是当天已保存的任务与动作状态（进行中/已完成/部分完成/已放下），缺位处才补新推荐。为此推荐会话日志保存所选任务的展示快照，并提供按用户与日期读取当天会话的正式只读端点。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 推荐会话日志（basic 与 agentic 两条路径）保存任务快照（task_id、标题、说明、预计分钟、领域）
- [ ] 新增 GET 端点：读取某用户某一天的推荐会话（含任务快照、task_events、feedback）
- [ ] 前端 getToday 优先读回当天会话并恢复状态；无记录或不足时才跑新推荐补位
- [ ] 刷新页面后当天进度可恢复（有针对性测试）
