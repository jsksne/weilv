# 03 — AI 建议直接转为行动（F2）

**What to build:** 建议卡提供"开始这件事"与"加入今日"。今日已有同一未结束任务则定位/显示"继续"；已完成显示"今天已完成"；没有则通过正式执行记录加入今日并双向同步；保存中阻止重复提交，失败可重试不冒充成功。

**Blocked by:** 01 — 今日列表读回（今日条目与执行记录的统一身份是前提）。

**Status:** ready-for-agent

- [ ] 建议卡主动作/次动作按今日状态分流：开始/继续、加入今日、今天已完成
- [ ] 加入今日绑定真实 recommendationId（agentic 会话日志），不捏造 ID
- [ ] 对话卡、今日卡、执行面板共享同一执行记录与状态来源
- [ ] 重复点击不重复添加；失败保留建议卡并提供重试（有针对性测试）
