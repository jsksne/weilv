# 04 — 任务进行中界面（F3）

**What to build:** 从今日卡或 AI 建议卡打开任务执行面板：任务名称、正式步骤、必要说明与"完成了 / 做了一部分 / 先放下"。关闭面板不结束任务；"先放下"可恢复、不算完成或失败；可选计时不自动完成。

**Blocked by:** 03 — 建议转行动（面板与两个入口共享同一执行记录）。

**Status:** ready-for-agent

- [ ] 复用现有任务详情层/面板承载执行界面，不新增顶层页面
- [ ] 开始 → 关闭 → 再打开可继续；部分完成与全部完成保持区别
- [ ] "先放下"保留可恢复状态，与"跳过"语义关系明确
- [ ] 可选计时不虚增完成记录，到点由用户确认（有针对性测试）
