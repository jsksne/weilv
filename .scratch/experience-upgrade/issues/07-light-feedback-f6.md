# 07 — 完成后一次轻反馈（F6）

**What to build:** 完成或部分完成保存成功后，可一次性回答"这次感觉怎么样？"（合适/有点费劲/没什么帮助）；不答可离开；反馈与完成状态分开保存并绑定同一执行记录；可修改替换；保存失败不影响完成状态。

**Blocked by:** 04 — 执行面板（反馈入口所在）；05 — 保存收口（完成保存语义）。

**Status:** ready-for-agent

- [ ] 轻反馈以正式反馈链路保存，绑定真实执行记录，主观词映射到允许取值不伪造未答项
- [ ] 跳过反馈仍算完成；修改反馈不增加任务数
- [ ] 反馈保存失败只影响反馈，提供重试（有针对性测试）
