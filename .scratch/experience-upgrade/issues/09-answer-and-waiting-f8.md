# 09 — 回答呈现与等待体验（F8）

**What to build:** 回答默认顺序为直接回应 → 建议/澄清 → 动作 → 可展开过程；支持"停止等待"（保留已显示内容并标识中断，迟到结果不污染后续消息，用户停止不触发自动重试）；消息级错误与重试不重复追加提问；上滑不抢滚动。

**Blocked by:** 02 — 连续对话（多消息会话是错误/重试/滚动语义的载体）。

**Status:** ready-for-agent

- [ ] 停止等待后旧请求结果不覆盖新消息；不自动发起非流式备用请求
- [ ] 重试同一轮不重复追加用户消息
- [ ] 用户上滑后不强制回底，提供回到最新（有针对性测试）
