## 入库前检查

每份资料必须完成：

- [ ] 官方机构与网址核验；
- [ ] 当前有效版本核验；
- [ ] 发布时间与获取日期记录；
- [ ] 原始文件或网页正文保存；
- [ ] 版权或许可说明记录；
- [ ] 适用年龄和适用场景标注；
- [ ] 医疗内容与日常健康行为内容分离；
- [ ] 风险、停止条件和求助条件提取；
- [ ] 人工审核人和审核日期记录。

## 暂不入库

- 自媒体、短视频、问答社区和营销文章；
- 没有原始出处的健康口诀；
- 面向成人或老年人的久坐研究直接改写出的青少年建议；
- 药物、器械、诊断和治疗方案；
- 仅由大模型生成、无法回溯原文的知识或任务。
